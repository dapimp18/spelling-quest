Submit this week's words

Type the week's spelling words below. Submitting takes you to GitHub to create an issue with your list — once you confirm it there, an automated workflow generates a hint and example sentence for each word and publishes them to the site within a minute or two. No GitHub account on this device? You can just note the words down and submit from wherever you're signed in.

What happens next

  1. GitHub opens a pre-filled "new issue" form — sign in if asked, then click Create.
  2. Only the site owner's submission is processed automatically (this prevents random visitors from publishing words).
  3. A GitHub Action generates kid-friendly hints and example sentences with Claude, updates the word list, and publishes it.
  4. You'll see a comment on the issue confirming it worked (or explaining what went wrong).
